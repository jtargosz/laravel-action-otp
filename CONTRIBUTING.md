# Contributing

Thanks for helping.

## Issues

Check open issues first. Include PHP version, Laravel version, package version and a short snippet that reproduces the problem.

## Pull requests

- Keep changes small and focused.
- Add or update tests in `tests/`.
- Run `vendor/bin/pint`, `vendor/bin/phpunit` and `vendor/bin/phpstan` before push.
- Do not change public API without a note in the PR description.

## Translations

Fixes to `lang/` are welcome. Keep the same keys as `lang/en/action-otp.php`.
